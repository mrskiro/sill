Support

Sill is free, open-source software maintained by one person. Help is on GitHub.

Something is broken

Open a bug report. The fastest way is from inside the app, because it fills in the app and OS version for you:

  • Mac: Help › Report an Issue…
  • iPhone: the Sync screen › Report an Issue
  • Or directly: New issue on GitHub

Say what you expected, what happened instead, and the shortest way you know to make it happen again. "Not sure" is a fine answer.

Sync is not working

Both apps write a sync.log. On the Mac, Help › Reveal Sync Log in Finder opens it. It names your devices and includes the first characters of pairing codes, so read it before pasting any of it into an issue. Common causes to check first: both devices on the same network or with Wi-Fi on, the iPhone app in the foreground, and the Local Network permission granted on both.

Questions and ideas

Open an issue as well. Feature requests are welcome, though Sill is deliberately small and many will be declined to keep it that way.
