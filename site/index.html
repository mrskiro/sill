Sill

A small local-first Markdown notepad for Mac and iPhone.
No account. No server.

GitHub Download for Mac

Free, open source (MIT). macOS 26 or later.

Fast
⌥S opens a floating panel over whatever you are doing. Esc hides it.
Local-first
Notes live in a single SQLite file on your device. Nothing waits on a network.
Direct sync
Pair once with a QR code. Your iPhone and Mac sync over mutual TLS when they are near each other.
Plain Markdown
No smart quotes, no auto-capitalization. What you type is what is stored.
Quiet
No menu bar icon, no background updater. It checks for updates only when you ask.
Mac
Download the disk image and drag Sill to Applications. Signed and notarized.
iPhone
Not on the App Store yet. Build from source with Xcode 26.6 or later, then pair from the Mac's Settings. 
git clone https://github.com/mrskiro/sill
cd sill && brew install xcodegen && make gen
open Sill.xcodeproj   # run the SillPhone scheme
